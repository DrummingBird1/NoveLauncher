## מה זה

NoveLauncher מחליף את מסך הבית של אנדרואיד. הוא מדרג ומקבץ את האפליקציות שלך
לפי השימוש האמיתי שלך — מה אתה פותח, מתי, ובאיזו תדירות — כך שמה שאתה צריך
כבר נמצא מולך.

הדירוג רץ **לגמרי על המכשיר שלך**. בלי חשבון, בלי שרת, בלי אנליטיקס, בלי
פרסומות. נתוני השימוש שלך לא עוזבים את הטלפון.

## פרטיות

זה כל העניין של הפרויקט, אז שווה לדייק:

- **שום דבר לא נאסף.** בלי אנליטיקס, בלי טלמטריה, בלי דיווח קריסות בגרסאות
  שמופצות, בלי חשבון, בלי פרסומות.
- **נתוני שימוש נשארים מקומיים.** נתוני השימוש נקראים מסטטיסטיקות השימוש של
  אנדרואיד ומעובדים על המכשיר; מה שההצעות לומדות נשמר במסד נתונים מקומי. שום
  דבר מזה לא מועלה.
- **ארבע תכונות משתמשות ברשת — ושום דבר אחר:**
  - **מזג אוויר** — שואל את [Open-Meteo](https://open-meteo.com) על מזג האוויר
    הנוכחי. מיקום מקורב נשלח רק אם נתת הרשאת מיקום; בלעדיה נשאל מזג האוויר של
    עיר ברירת מחדל.
  - **חדשות** — עמוד החדשות מושך את פידי ה-RSS שהפעלת, ישירות מכל אתר.
  - **גיבויים** — רק אם בחרת ב-NAS: השרת שלך, דרך HTTPS.
  - **בדיקת עדכונים** — כבויה כברירת מחדל. כשמפעילים אותה, האפליקציה שואלת את
    ממשק הגרסאות של GitHub מה הגרסה האחרונה, לכל היותר פעם ביום. שום מידע עליך
    או על המכשיר לא נשלח, ושום דבר לא מורד אוטומטית.

  כל השאר נשאר על המכשיר.
- **הגיבויים שלך.** בטלפון או ב-NAS שלך. אפשר להצפין ייצוא בסיסמה שרק אתה
  מחזיק.
- **הלוח העברי מחושב בטלפון.** זמני החגים, הדלקת הנרות וצאת השבת מחושבים לפי
  המיקום המקורב שלך אם אישרת (אחרת לפי עיר ברירת מחדל), ולא נשלחים לשום מקום.
- **עוזר המחוות לא קורא כלום.** הקשה כפולה לכיבוי המסך משתמשת בשירות נגישות
  אופציונלי שמבצע בדיוק שתי פעולות (כיבוי מסך, פתיחת התראות) ולא יכול לראות מה
  מופיע על המסך.

## הורדה

הורד את קובץ ה-APK החתום מ[**הגרסה האחרונה**](https://github.com/DrummingBird1/NoveLauncher/releases/latest).

תצטרך לאשר התקנה ממקורות לא ידועים באפליקציה שאיתה הורדת. כל הגרסאות חתומות
באותו מפתח, כך שעדכונים מותקנים חלק אחד מעל השני.

### דרישות מערכת

- אנדרואיד 8.0 (API 26) ומעלה
- כ-25 MB אחסון

כמה תכונות דורשות יותר: המרחב הפרטי דורש אנדרואיד 15, והקשה כפולה לכיבוי המסך
דורשת אנדרואיד 9. המרחב הפרטי, קיצורי הדרך והשהיית אפליקציות העבודה עובדים רק
כש-NoveLauncher מוגדר כאפליקציית הבית שלך.

## בנייה מהמקור

```bash
git clone https://github.com/DrummingBird1/NoveLauncher.git
cd NoveLauncher/android
./gradlew assembleDebug
```

פתח את התיקייה **`android/`** בגרסת Android Studio שתומכת ב-Android Gradle
Plugin 9.4 — לא את שורש המאגר, שאינו פרויקט Gradle. כדי להריץ את Gradle צריך
**JDK 21** (הגדר אותו כ-Gradle JDK ב-Android Studio); האפליקציה עצמה מקומפלת
ל-bytecode של Java 17.
