## מה זה

NoveLauncher מחליף את מסך הבית של אנדרואיד. הוא מדרג ומקבץ את האפליקציות שלך
לפי השימוש האמיתי שלך — מה אתה פותח, מתי, ובאיזו תדירות — כך שמה שאתה צריך
כבר נמצא מולך.

הדירוג רץ **לגמרי על המכשיר שלך**. בלי חשבון, בלי שרת, בלי אנליטיקס, בלי
פרסומות. נתוני השימוש שלך לא עוזבים את הטלפון.

## פרטיות

זה כל העניין של הפרויקט, אז שווה לדייק:

- **שום דבר לא נאסף.** בלי אנליטיקס, בלי טלמטריה, בלי דיווח קריסות בגרסאות
  שמופצות, בלי חשבון, בלי פרסומות.
- **נתוני שימוש נשארים מקומיים.** סטטיסטיקות השימוש נשמרות במסד נתונים על
  המכשיר ומשמשות רק לדירוג האפליקציות.
- **הקריאה היחידה לרשת** היא ווידג'ט מזג האוויר, ששולח מיקום מקורב ל-[Open-Meteo](https://open-meteo.com)
  — ורק אם נתת הרשאת מיקום. בלי ההרשאה, מזג האוויר נופל לעיר ברירת מחדל.
- **הגיבויים שלך.** מקומי, ה-Google Drive שלך, או ה-NAS שלך. אפשר להצפין
  ייצוא בסיסמה שרק אתה מחזיק.

פירוט מלא: [**מדיניות פרטיות**](https://drummingbird1.github.io/NoveLauncher/privacy.html) ·
[תנאי שימוש](https://drummingbird1.github.io/NoveLauncher/terms.html)

> **לגבי נעילת אפליקציות:** נעילת האפליקציות, התיקייה הפרטית והאפליקציות
> המוסתרות הן **הרתעה, לא ארגז חול מאובטח**. אפליקציה "נעולה" עדיין נגישה
> דרך היסטוריית האפליקציות, התראות, לאנצ'ר אחר או ADB — זה נכון לגבי כל
> לאנצ'ר צד-שלישי. לבידוד אמיתי, השתמש בפרופיל העבודה המובנה של אנדרואיד.

## הורדה

הורד את קובץ ה-APK החתום מ[**הגרסה האחרונה**](https://github.com/DrummingBird1/NoveLauncher/releases/latest).

תצטרך לאשר התקנה ממקורות לא ידועים באפליקציה שאיתה הורדת. כל הגרסאות חתומות
באותו מפתח, כך שעדכונים מותקנים חלק אחד מעל השני.

### דרישות מערכת

- אנדרואיד 8.0 (API 26) ומעלה
- כ-25 MB אחסון

## בנייה מהמקור

```bash
git clone https://github.com/DrummingBird1/NoveLauncher.git
cd NoveLauncher/android
./gradlew assembleDebug
```

פתח את התיקייה **`android/`** ב-Android Studio (Ladybug ומעלה) — לא את שורש
המאגר, שאינו פרויקט Gradle.
