## ما هو

يستبدل NoveLauncher الشاشة الرئيسية لجهاز أندرويد. يرتّب تطبيقاتك ويجمّعها
بناءً على استخدامك الفعلي — ما تفتحه، ومتى، وكم مرة — بحيث يكون ما تحتاجه
أمامك مباشرة.

يعمل الترتيب **بالكامل على جهازك**. بدون حساب، بدون خادم، بدون تحليلات،
بدون إعلانات. بيانات استخدامك لا تغادر هاتفك أبدًا.

## المزايا

| | |
|---|---|
| 🧠 **اقتراحات تتعلّم** | التطبيقات مرتّبة حسب آخر استخدام والتكرار ووقت اليوم والفئة، وقسم "مُقترح الآن" يتعلّم أيضًا من الاقتراحات التي تفتحها فعلًا — كل ذلك يُحتسب محليًا |
| 📁 **مجلدات ذكية** | تجميع تلقائي في 11 فئة، بدون فرز يدوي |
| 💼 **ملف العمل والمساحة الخاصة** | تطبيقات العمل بشارتها مع مفتاح للإيقاف المؤقت؛ والمساحة الخاصة في أندرويد 15 في قسم مستقل قابل للقفل، لا تختلط بالاقتراحات وتُخفى من البحث وهي مقفلة |
| ⚡ **اختصارات التطبيقات** | اضغط مطوّلًا على تطبيق لتصل إلى اختصاراته — رسالة جديدة، مسار محفوظ — مباشرة من الشاشة الرئيسية |
| 🔍 **بحث ذكي** | التطبيقات وجهات الاتصال والإعدادات من مربع واحد. مطابقة بين العبرية والإنجليزية ("וואטסאפ" يجد WhatsApp)، وتسامح مع الأخطاء الإملائية والأحرف الأولى ("gm" ← Google Maps)، إضافةً إلى آلة حاسبة وتحويل الوحدات |
| 🕯️ **التقويم العبري ووضع السبت** | التاريخ العبري، والأعياد (تقويم إسرائيل أو الشتات)، ومواعيد إشعال الشموع والهافدالا محسوبة على الهاتف؛ ويُخفي وضع السبت الاقتراحات المشتّتة وشارات الإشعارات من إشعال الشموع حتى حلول الليل |
| 🖼️ **الخلفيات** | صورك الخاصة أو تدرّجات مدمجة — خلفية واحدة للكل، أو لكل صفحة، أو حسب الساعة، أو حسب يوم الأسبوع، أو خلفية النظام (بما فيها الحيّة) — مع السطوع والتباين والتشبّع والدفء والتمويه والتظليل |
| 👆 **الإيماءات** | السحب لأعلى للتطبيقات، والسحب لأسفل للإشعارات، والنقر المزدوج لإطفاء الشاشة |
| 🎨 **تخصيص عميق** | 12 نمط ألوان، Material You، ألوان مخصصة، 16 خطًا، 12 شكل أيقونة |
| 🧷 **حزم الأيقونات** | طبّق أي حزمة أيقونات متوافقة مع Nova / ADW / Lawnchair؛ التطبيقات التي لا تغطيها الحزمة تحتفظ بأيقونتها |
| 🔒 **قفل التطبيقات** | رمز PIN أو كلمة مرور أو نمط أو بصمة لتطبيقات محددة، مع مجلد خاص وتطبيقات مخفية |
| 🌍 **7 لغات** | العربية والعبرية والإنجليزية والفرنسية والروسية والإسبانية والألمانية — بدعم كامل للكتابة من اليمين لليسار |
| 📰 **موجز الأخبار** | مصادر مدمجة بالإضافة إلى موجزات RSS خاصة بك |
| 💾 **النسخ الاحتياطي** | محلي أو على NAS/WebDAV الخاص بك، وفق جدول زمني، مع تشفير اختياري بكلمة مرور |
| 📊 **إحصائيات الاستخدام** | وقت الشاشة واستخدام التطبيقات حسب اليوم أو الأسبوع أو الشهر، تُقرأ من أندرويد على جهازك |
| 🧩 **الأدوات وشريط التطبيقات** | أدوات أندرويد القياسية (مع شاشات إعدادها وقابلة لتغيير الحجم) وشريط سفلي مثبّت |

## الخصوصية

هذا هو جوهر المشروع، لذا من المهم أن نكون دقيقين:

- **لا يُجمع أي شيء.** بدون تحليلات، بدون تتبّع، بدون تقارير أعطال في
  الإصدارات المنشورة، بدون حساب، بدون إعلانات.
- **بيانات الاستخدام تبقى محلية.** يُقرأ استخدام التطبيقات من إحصائيات
  الاستخدام في أندرويد ويُعالَج على جهازك؛ وما تتعلّمه الاقتراحات يُحفظ في
  قاعدة بيانات محلية. لا يُرفع شيء من ذلك.
- **أربع ميزات فقط تستخدم الشبكة — ولا شيء غيرها:**
  - **الطقس** — يطلب الحالة الحالية من [Open-Meteo](https://open-meteo.com).
    لا يرسل إحداثياتك التقريبية إلا إذا منحت إذن الموقع؛ وبدونه يطلب طقس
    مدينة افتراضية.
  - **الأخبار** — تجلب صفحة الأخبار موجزات RSS التي فعّلتها، مباشرة من كل ناشر.
  - **النسخ الاحتياطي** — فقط إن اخترت NAS: خادمك الخاص، عبر HTTPS.
  - **التحقق من التحديثات** — معطّل افتراضيًا. عند تفعيله، يسأل التطبيق واجهة
    الإصدارات في GitHub عن أحدث إصدار مرة واحدة في اليوم على الأكثر. لا يُرسل
    أي شيء عنك أو عن جهازك، ولا يُنزَّل أي شيء تلقائيًا.

  كل ما عدا ذلك يبقى على جهازك.
- **نسخك الاحتياطية ملكك.** على الهاتف أو على NAS الخاص بك، مع إمكانية
  التشفير بكلمة مرور تملكها وحدك.
- **التقويم العبري يُحسب على الهاتف.** مواعيد الأعياد وإشعال الشموع والهافدالا
  تعتمد على موقعك التقريبي إن سمحت بذلك (أو على مدينة افتراضية)، ولا تُرسل إلى
  أي مكان.
- **مساعد الإيماءات لا يقرأ شيئًا.** النقر المزدوج لإطفاء الشاشة يستخدم خدمة
  إمكانية وصول اختيارية تنفّذ إجراءين فقط (إطفاء الشاشة وفتح الإشعارات) ولا
  يمكنها رؤية ما على شاشتك.

التفاصيل الكاملة: [**سياسة الخصوصية**](https://drummingbird1.github.io/NoveLauncher/privacy.html) ·
[شروط الاستخدام](https://drummingbird1.github.io/NoveLauncher/terms.html)

> **بخصوص قفل التطبيقات:** قفل التطبيقات والمجلد الخاص والتطبيقات المخفية هي
> **رادع وليست بيئة معزولة آمنة**. التطبيق "المقفل" يبقى قابلاً للوصول عبر
> التطبيقات الأخيرة أو الإشعارات أو مشغّل آخر أو ADB — وهذا ينطبق على كل
> مشغّل خارجي. للعزل الحقيقي، استخدم ملف تعريف العمل المدمج في أندرويد أو
> المساحة الخاصة (أندرويد 15 فأحدث) — وNoveLauncher يدعم الاثنين.

## التنزيل

نزّل ملف APK الموقّع من [**أحدث إصدار**](https://github.com/DrummingBird1/NoveLauncher/releases/latest).

ستحتاج إلى السماح بالتثبيت من مصادر غير معروفة. جميع الإصدارات موقّعة بالمفتاح
نفسه، لذا تُثبَّت التحديثات فوق بعضها بسلاسة.

<a href="https://github.com/ImranR98/Obtainium"><img src="../assets/badge-obtainium.png" alt="Get it on Obtainium" height="62"></a>

**تحديثات تلقائية:** يثبّت [Obtainium](https://github.com/ImranR98/Obtainium) تطبيق NoveLauncher مباشرةً من
إصدارات GitHub هذه ويحافظ على تحديثه. في Obtainium، أضف تطبيقًا والصق
`https://github.com/DrummingBird1/NoveLauncher`.

### متطلبات النظام

- أندرويد 8.0 (API 26) أو أحدث
- حوالي 25 ميغابايت من مساحة التخزين

بعض الميزات تحتاج إلى المزيد: المساحة الخاصة تتطلب أندرويد 15، والنقر المزدوج
لإطفاء الشاشة يتطلب أندرويد 9. وتعمل المساحة الخاصة واختصارات التطبيقات وإيقاف
تطبيقات العمل مؤقتًا فقط عندما يكون NoveLauncher هو تطبيق الشاشة الرئيسية
الافتراضي.

## البناء من المصدر

```bash
git clone https://github.com/DrummingBird1/NoveLauncher.git
cd NoveLauncher/android
./gradlew assembleDebug
```

افتح مجلد **`android/`** في إصدار من Android Studio يدعم Android Gradle Plugin
9.4 — وليس جذر المستودع، فهو ليس مشروع Gradle. يحتاج Gradle إلى **JDK 21**
(اضبطه كـ Gradle JDK في Android Studio)؛ أما التطبيق نفسه فيُترجم إلى bytecode
لـ Java 17.
